# N.R.D. (Nageppanashi Race Director)

N.R.Dは、FPVドローンレースの運営進行をサポートするために作成したブラウザベースのWebアプリケーションです。

既存の素晴らしい計測ソフトや、AI実況をはじめとする最先端の配信ツールを外から拝見する中で、「もっとこんな画面や演出が出せたら面白いかもしれない」と思い立ちました。プロの領域とは全く違う、素人なりのアプローチで自己満足的に機能を継ぎ足し続け、現在の形に組み上がったシステムです。

## Concept: 現場を止めない、少しでも盛り上げる
本システムは高度なサーバーやデータベースを持たず、ローカル環境のブラウザ（HTML/JS）単体で泥臭く動作します。

1. **ローカル完結による運用継続（コア）**
   通信トラブル等によるシステム停止リスクを避けるため、全てのデータ処理はブラウザの内部（IndexedDB）で完結するように設計しています。万が一ブラウザが終了してしまっても、自動保存されたデータから直前の状態に復帰し、なんとかレースの進行を止めずに済む仕組みを目指しました。
2. **小さなエンタメ要素の付加**
   正確なタイム計測は既存のシステムにお任せし、N.R.Dは「演出」に重きを置いています。ベストラップ更新や順位変動を検知して画面にテロップを出したり、OBSと連携して短いリプレイ動画を再生したりと、会場の雰囲気を少しでも盛り上げるための機能を追加しています。

## Architecture & Required Software
N.R.Dは単体では計測ができません。先人たちが開発された以下のソフトウェアと連携させていただく形で動作します。

*   **N.R.D (index.html)**
    *   本システムです。Chrome等のブラウザで開き、大会のブラケット（トーナメント表）管理やUI表示、各ソフトへの連携コマンド送信を行います。
*   **Tiny View Plus (カスタム改修版)**
    *   FPV映像の表示とARマーカーによるラップ計測を行う素晴らしいシステムです。N.R.Dと連動させるため、ラップ通過時に軽量なイベント（JSON）を出力する処理などをTVP側（C++）に独自追加して運用しています。
*   **OBS Studio**
    *   配信・録画ソフトです。OBS WebSocket (v5) を経由してN.R.Dから録画の開始/停止を行い、リプレイバッファ機能を利用してハイライト動画（AUTO REPLAY）を自動保存・再生します。

## Key Features
*   **GUI Bracket Builder:** ドラフト生成アルゴリズムによるヒート組みの補助と、画面上でのブラケット編集機能。
*   **Series Manager:** 長期的なシリーズ戦のためのポイント計算、有効ポイント制の集計、表記揺れのあるパイロット名の統合（名寄せ）機能。
*   **Auto Replay System:** レース中の順位変動やベストラップ更新を検知し、OBSのリプレイバッファに保存。ヒート終了後にN.R.D上で動画を再生する簡易ハイライト機能。
*   **Live Viewer Sync:** レースの進行状況（現在順位や次のヒート情報）を、GAS（Google Apps Script）経由で観客のスマートフォンへ簡易的にテキスト配信する機能。
*   **Lap Fixer:** 誤検知によるラップのズレを、後から等分分割したり無効化したりして手動補正する機能。

## How to Use
N.R.DはWebサーバーへのデプロイは不要で、ローカルPC上で動作します。

### 1. Boot Sequence (起動とディレクトリ接続)
1. ローカルサーバー（VS CodeのLive Server等）経由で `index.html` をブラウザで開きます。
2. 起動画面にて、連携する各種ローカルディレクトリの読み書き権限をブラウザに付与します。
   * **TVP RESULTS:** Tiny View Plus の `data` フォルダ（リザルトファイルとJSONを読み込みます）。
   * **OBS VIDEO:** OBSがリプレイバッファを保存する動画フォルダ。
   * **PILOT ICONS:** パイロットのアイコン画像を格納したフォルダ。
   * **BGM PLAYLIST:** 会場BGM用の音声ファイル（mp3等）を入れたフォルダ。
3. 接続が完了したら `[ IGNITION ]` をクリックしてUIを起動します。（次回以降は `[ QUICK BOOT ]` で一括再接続が可能です）

### 2. Race Direction (レース進行)
1. 画面下部の `[ 🎤 DIRECTOR ]` から、CSV読み込みや前回の結果を利用してヒート構成（ドラフト）を作成し、ブラケットに展開します。
2. `[ ▼ CONTROLS ]` パネルから目的のヒートを `ACTIVE` にし、レースをスタート（録画開始）します。
3. 制限時間や規定周回数に達すると自動（または手動 `Space` キー）で計測・録画を終了します。
4. 終了後、必要に応じて `[ ⚖️ JUDGE ]` 画面からラップ修正を行い、`[ ■ FINISH HEAT ]` で順位を確定させます。

## Keyboard Shortcuts
現場でのマウス操作の負担を減らすため、以下のショートカットキーを用意しています。

| Key | Action |
| :--- | :--- |
| **`1`** | Change View (Dual / Best / Race の画面切り替え) |
| **`2`** | View: BRACKET (トーナメント表表示) |
| **`3`** | View: OVERALL (総合順位表示) |
| **`4`** | View: SERIES (シリーズランキング表示) |
| **`D`** | Toggle Dashboard (コントロールパネル開閉) |
| **`F`** | Toggle Fullscreen (フルスクリーン切替) |
| **`O`** | Open Director Modal (ディレクター画面開閉) |
| **`S`** | Toggle Auto Scroll (自動スクロール ON/OFF) |
| **`A`** | Call Active/Waiting Heat (ヒート開始アナウンス) |
| **`E`** / **`Enter`** | Finish Active Heat / Start Next (ヒート確定 / 次へ進む) |
| **`Space`** | Stop TVP (TVP計測強制終了) |
| **`P`** | Toggle Ceremony (表彰式用BGM演出) |
| **`J`** | Toggle BGM Play / Pause |
| **`K`** | Play Next BGM (次の曲へ) |
| **`[`** / **`]`** | BGM Volume Down / Up |
| **`Z, X, C, V...`** | Manual Lap Trigger (カメラ枠順の手動ラップ追加) |
| **`Shift + Z, X...`**| Manual Lap Delete (カメラ枠順の手動ラップ削除) |
